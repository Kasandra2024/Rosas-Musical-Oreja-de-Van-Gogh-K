# Rosas-Musical-Oreja-de-Van-Gogh-K

Una rosa interactiva bajo una cúpula de cristal con efectos mágicos, animación de pétalos y música de fondo de **La Oreja de Van Gogh**.

## Características

* **Rosa interactiva:** Animación detallada con efectos visuales y pétalos dinámicos.
* **Experiencia musical:** Integración de melodías románticas para ambientar la experiencia.
* **Diseño responsivo:** Adaptado para visualizarse de forma fluida en diferentes pantallas.

## Tecnologías utilizadas

* **HTML5** para la estructura de la página.
* **CSS3** para los estilos, animaciones y efectos mágicos de la cúpula.
* **JavaScript (ES6)** para la interactividad y la gestión de la música.

##  Cómo ejecutar el proyecto

1. Clona este repositorio o descarga los archivos.
2. Abre el archivo `index.html` en tu navegador web favorito para disfrutar de la experiencia.
